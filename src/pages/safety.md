> 本页为个人观测整理，不构成医疗建议。出现下面任何一条"立即"级别的信号，先处理身体，不要先来评论区。

## A. 立即停戴（取出，当日不再佩戴）

- [ ] 出血：便后纸上有血、黏液带血、滴血（任何量）
- [ ] 脓性/黄绿色/恶臭分泌物
- [ ] 刺痛、刀割样疼痛，或体位改变时出现的锐痛
- [ ] 肛周/臀部/大腿麻木、放射痛
- [ ] 发热、寒战、下腹压痛、腹胀不排气 → **直接急诊**
- [ ] 无法自主收紧，或出现漏气/漏液
- [ ] 压痕超过 2 小时不消退，或皮肤破损、水泡
- [ ] 疼痛性质与既往不同（这是最有价值的一条判据，因为你自己最清楚"往常"是什么）

## B. 停戴并观察 48–72 小时（不缓解则就医）

- [ ] 持续钝痛/坠胀，取出后仍存在
- [ ] 排便明显疼痛但无血
- [ ] 黏液量突然翻倍、伴里急后重（总想排但排不出）
- [ ] 肛缘肿物脱出、需要手法回纳

## C. 绝对禁忌（不是"要小心"，是"不要做"）

- [ ] 已有炎症性肠病、痔急性发作期、肛裂、直肠脱垂、盆底功能障碍、既往肛肠手术恢复期
- [ ] 正在使用抗凝/抗血小板药物
- [ ] 使用止痛药或局麻药"辅助佩戴"
- [ ] 未成年人、无法自主表达/自主取出的情形
- [ ] 睡眠中无人可呼叫的情况下首次尝试长时间留置
- [ ] 任何没有**机械止挡或宽法兰**的体内件；任何可滑入腔内的直径比
- [ ] 多孔材料（TPE、果冻胶、PVC、发泡）作为长时留置件
- [ ] 在尾巴上系绳索、锁扣、牵引带

:::danger 器械滑入且自行取不出
**不要**：用手深挖、使用泻药、高压灌肠、"再等等看能不能自己出来"。
**要做**：尽快就诊（急诊/肛肠外科），如实说明是什么、什么时候、什么材质。这类病例在急诊并不罕见，金属件在 X 光下清清楚楚，医生需要的是信息不是道德评判。延误只会把简单的低位取出变成剖腹取物。
:::

## D. 每日自检流程（5 分钟）

1. **手镜 + 冷光手电**：肛周皮肤颜色、压痕范围、有无破损/擦伤/发白。
2. **触诊**：坐骨承重位与站立位各按一次，找异常硬结与压痛点。
3. **功能测试**：自主收紧 3 秒，能否清楚感觉到一次明确收缩。
4. **器材**：扭转头部检查位移、目视硅胶表面缺口、试拧接口感受是否变涩。
5. 记录到日志（字段见主报告 §4），趋势比单日数值重要。

## E. 就医时值得带的信息

- 器材材质与结构（金属/硅胶、是否实心）——医生最关心"会不会碎"和"能不能看见"
- 留置总时长、最后一次佩戴时间
- 症状起始与变化曲线（这就是日志的意义）
- 当前用药、过敏史

## F. 关于"23/1"

23/1 是我在特定阶段（低活动量、体重下降期、器材恰好定型）形成的作息，**是结果，不是目标，更不是资格认证**。它每天真正被验证的只有那 1 小时窗口里的四个指标。

如果你今天的身体只支持 4 小时/20 小时休息，那 4/20 就是你正确的配置。在这个话题上，"更少"永远比"更多"更接近专业。
