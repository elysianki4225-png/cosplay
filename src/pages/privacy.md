## 1. 本页两张图的来源

两条 `gate: "external"` 图位，`data-raw` 指向你自己那个图床的直链：未解锁时页面里只有 CSS 马赛克底 + 一行提示，**`<img>` 元素由点击后的 JS 现场插入**，所以源码、搜索引擎、图片爬虫都拿不到那张图。图床侧的可访问性、保留期、是否被抓取，与本站无关——这也是 §3 第 1 条要表达的意思。

想改成"原图只留本地"：把图放进 `ui/photos/`（已 gitignore），跑 `bash build/blur.sh`，再把图位的 `gate` 从 `external` 改成 `local` 并填 `src`。此后仓库里只会出现丢弃过像素的打码版。

## 2. 技术实现（可复核）

| 环节 | 做法 | 为什么这么做 |
|---|---|---|
| 源图存放 | `ui/photos/`，已进 `.gitignore` | 原图永远不进仓库、不进 git 历史。**进了历史就再也删不干净**，这条没有妥协空间 |
| 打码 | `-strip`（去 EXIF/GPS/机型）→ 降采样到 2% 再放大（像素真被丢弃）→ `blur 0x7` 抹掉马赛克块边界 | 只做 CSS `filter: blur()` 的话，F12 删一行样式就还原了，那叫自欺欺人 |
| 尺寸上限 | 最长边 1600 px | 原图分辨率往往够辨认纹身、门窗牌、房间布局，必须降 |
| 封面 | 列表与详情共用同一张打码图（含 480×360 thumb） | 不给"缩略图反而是清晰的"留漏洞 |
| 未解锁时 | HTML 里只有 `data-raw` 属性，没有 `<img src>`；alt 文本也是空的 | 搜索引擎与图片爬虫抓不到内容 |
| 解锁 | 点击按钮 → JS 现插 `<img>`；状态存 `sessionStorage` | 关掉标签页自动回到打码态；在自习室、公司电脑上借用浏览器不会留下"下次打开还是开的" |
| 整页展开 | 链接尾部加 `#unlocked`，`#locked` 复位 | 自己看的时候省事。**别把 `#unlocked` 这个链接发给任何人** |
| 外部图床 | `gate: "external"` 的图位，本站不下载、不代理、不缓存原图 | 原图不在我手上，也不该在我手上 |

## 3. 三个诚实的结论（比"我们很重视隐私"有用）

1. **挂到公网图床的那一刻，"能不能被看到"就不再由此页决定了。**图床没有访问控制、没有过期时间、往往能被搜索引擎抓取，而且 URL 一旦泄露就是永久泄露。本页这两张就是这种状态——请你自己判断是否接受。
2. **真正的访问控制只有三种**：Cloudflare Access / GitHub Pages 私有仓库 + 鉴权代理 / 自己托管 + Basic Auth。客户端一律不可信，这是常识，不是我的偏好。
3. **最稳的做法是不上传。**要给别人看，就走限时限人的通道（阅后即焚、本地传输），并在文件里去掉一切可识别信息。本站的图位系统对这种方式同样适用——`status: "pending"` 时页面只显示占位块，不显示任何内容。

## 4. 未经授权传播会面临的法律责任

> 下面是中国大陆法域的条文梳理，供你判断与举证时对照使用，**不构成法律意见**；真要动手，先咨询执业律师。第 4.3 那条尤其值得读完，它和多数人的直觉相反。

### 3.1 民事责任（对传播者最常用的一击）

- <span class="law">《民法典》第 1032、1033 条</span>隐私权。**第 1033 条第（三）（四）（五）项**明确禁止：拍摄、窥视、窃听、**公开**他人私密活动；拍摄他人身体的**私密部位**；处理他人私密信息（均须权利人明确同意）。救济：停止侵害、删除、赔礼道歉、损害赔偿。
- <span class="law">《民法典》第 1018—1020 条</span>肖像权。**现行法已取消"以营利为目的"这一要件**——不赚钱也侵权。照片若能认出人脸/体态特征，这条与隐私权可同时主张。
- <span class="law">《民法典》第 1024 条</span>名誉权。若传播时配了侮辱、造谣、丑化文字，另行成立。
- <span class="law">《民法典》第 1183 条</span>侵害自然人人身权益造成严重精神损害的，可请求**精神损害赔偿**。
- <span class="law">《个人信息保护法》第 28、29、69 条</span>私密信息属**敏感个人信息**，处理须取得单独同意；第 69 条是**过错推定**——处理者自证无过错，否则按损失或所得赔偿。

### 3.2 行政责任（治安处罚）

- <span class="law">《治安管理处罚法》（2025 修订，2026-01-01 施行）</span>侵犯人身权利一节中明确列举"**偷窥、偷拍、窃听、散布他人隐私**"，处 **5 日以下拘留或 500 元以下罚款**；情节较重 **5—10 日拘留，可并罚 500 元**。（2026 年前的旧版为第 42 条第 1 款第（六）项，起诉/报案时按行为发生时的版本引用。）
- <span class="law">第 80 条</span>制作、运输、复制、出售、出租淫秽图片等物品，**或者利用信息网络传播淫秽信息**：**10—15 日拘留，可并处 5000 元以下罚款**；情节较轻 5 日以下拘留或 1000—3000 元罚款。涉未成年人的从重。
- <span class="law">第 70 条</span>非法安装、使用、提供窃听窃照专用器材的，另有处罚。

### 3.3 刑事责任（注意：这一条可能也指向"本人"）

- <span class="law">《刑法》第 364 条第 1 款 · 传播淫秽物品罪</span>传播淫秽图片，**情节严重**的，处 **2 年以下有期徒刑、拘役或管制**。司法解释口径的"情节严重"常以**传播人次**计（如 300 人次以上），或造成恶劣社会影响。
- <span class="law">《刑法》第 363 条 · 传播淫秽物品牟利罪</span>一旦**以牟利为目的**（收费群、卖图、引流变现），量刑直接跳到 3 年以下 → 情节严重 3—10 年 → 情节特别严重 10 年以上或无期。
- <span class="law">关键误区</span>：第 363、364 条保护的是**社会管理秩序**，不是个人隐私。**"图里的人同意"并不能豁免这一罪**——也就是说，当事人本人向不特定多数人散布，同样存在刑事风险。这也是本站把器材与工程放在首位、把佩戴实拍做成"最小可传播单元"的现实原因。
- <span class="law">向不满 18 周岁的人传播</span>，从重处罚（第 364 条第 4 款）。

### 3.4 平台与刑事交叉的其它情形

- 用图**要钱、要见面、要更多照片** → 敲诈勒索罪（《刑法》第 274 条）。这是**必须报警**的情形，见 §5。
- 在群里/网盘/贴吧传播 → 平台依《网络信息内容生态治理规定》等承担删除义务，同时可作为治安/刑事案件的平台取证来源。

## 5. 万一真的流传出去了：按顺序做

:::danger 第 1 步永远是取证，不是删除
**先固定证据，再联系删除。**一上来就慌着删，后面报警和起诉都会因为没有原始证据而卡死。取证要在同一小时内完成：链接、账号 ID、发布时间、转发量、评论截图；截图带系统时间；有预算就上"可信时间戳/区块链存证"或直接公证处网页取证公证。
:::

1. **取证**（同上）。把每个链接单独存一份，命名 `日期_平台_账号ID_内容哈希`。顺手记 `sha256sum 文件`，用于日后比对是否同一张。
2. **向平台投诉**：走"侵犯隐私/肖像权"通道，提交权利人身份与截图。同时用英文发一份 DMCA/侵权通知（GitHub 走 `support@github.com` 的 DMCA 流程，图床找 abuse 邮箱；Cloudflare 可提交 `https://abuse.cloudflare.com`）。要求"下架 + 提供上传者注册信息与登录日志"。
3. **对能联系到的传播者**：平台私信 → 书面（邮件/微信文字，留痕）要求**立即删除、说明扩散范围、书面道歉**。不要骂、不要谈判、不要给出任何补偿方案。
4. **被要挟**：**停止一切对话，不转一分钱，立刻报警**（保留全部原始对话作为证据）。给钱只会把周期拉长，实践中没有"给完就结束"这回事。
5. **报警**：按 §4.2 走治安案件（散布他人隐私）；扩散量大、有牟利、或以此为要挟时，请求按 §4.3 立案。带上打印好的取证包与 U 盘原件。
6. **民事起诉**：侵权地/被告住所地法院，请求删除、赔礼道歉、精神损害赔偿；同时申请**行为保全/禁令**阻止继续扩散。
7. **次生伤害**：如果家人、同事可能看到，提前准备一句最短的说明，并联系心理支持资源。这一步不是软弱，是止损。

## 6. 本站采取的预防性措施

- 原图不进仓库、不进 git 历史（`.gitignore` + `ui/photos/`）；构建只消费打码产物
- 含图位页面 `<meta name="robots" content="noindex,nosnippet">`，`robots.txt` 屏蔽 `/assets/images/gated/`
- 打码时强制 `-strip`，去掉 EXIF / GPS / 设备序列号
- 分辨率与尺寸统一降级（1600 px 上限 + 像素丢弃式马赛克）
- 页面顶部固定"用途边界"横幅：**道具是 Cosplay 装饰附件**，不是情趣用品；本站不推荐、不导购、不提供任何性用途层面的说明
- 不提供评论区、不接入任何统计/埋点/第三方脚本，图片路径不出现在 `sitemap.xml` 里
- 未成年人不得访问本页
