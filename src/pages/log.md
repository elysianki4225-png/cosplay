## 站点

### v1.0.0 · 2026-10-13
- 静态构建器：零依赖 `build/build.js`，自研 markdown 子集（callout / 表格 / 图位 / 脚注）
- UI Kit：`tokens.css + base.css + ui.css` 三层，构建时合并成单文件；亮/暗/跟随系统三态
- 图标：30 枚自绘 SVG symbol，构建时内联，不依赖任何 CDN 图标库
- 功能：站内搜索（`search.json` + 前端打分）、阅读进度、粘性目录、图片 lightbox、留置计时器
- 输出：RSS、sitemap、robots、404；`.nojekyll`；GitHub Actions 发布 Pages
- 图位系统：`src/slots.json`，缺图出占位块而非破图

### v0.9.0 · 2026-10-06
- 目录/正文双栏在 1080px 断点塌陷为单栏；表格窄屏横向滚动
- 修：暗色下 `blockquote` 边框对比度不足

## 器材
